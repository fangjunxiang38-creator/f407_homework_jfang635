- 两根线：SCL（主机产生时钟）+ SDA（双向数据），半双工
- 半双工：读寄存器要"先写地址、再读数据"（重复 START）
- 一主多从，靠 7 位地址点名（IST8310 = 0x0E）
- 开漏 + 上拉：线与总线（不能让设备主动驱动高电平，会短路）
- SPI 用的是推挽（Push-Pull）——每个脚能主动输出高和低，所以 SPI 不需要上拉，但也因此一根 CS 只能挂一个从机。
- 每字节有 ACK/NACK → 能直接发现"从机没响应"
- IST8310 的从机地址，0x0E（7 位）0x0E << 1（8位）
- 写：(0x0E << 1) | 0 = 0x1C
  读：(0x0E << 1) | 1 = 0x1D

| 寄存器 | 写什么 | 作用                                      |
| ------ | ------ | ----------------------------------------- |
| `0x0B` | `0x08` | 使能中断输出，且中断是低电平有效          |
| `0x41` | `0x09` | 平均次数设置（多次采样取平均，读数更稳）  |
| `0x42` | `0xC0` | **厂商要求必须写 0xC0**，不写就不正常工作 |
| `0x0A` | `0x0B` | 输出速率 = 200Hz                          |
